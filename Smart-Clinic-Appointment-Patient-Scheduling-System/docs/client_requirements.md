# Patient Requirements

## 1. Functional Requirements

### 1.1 Account Management

| ID | Requirement |
|---|---|
| PAT-01 | The system shall allow patients to register using their basic personal information. |
| PAT-02 | The system shall allow registered patients to log in using their email or username and password. |
| PAT-03 | The system shall allow patients to log out. |
| PAT-04 | The system shall allow patients to view their account information. |
| PAT-05 | The system shall allow patients to update their editable personal information. |
| PAT-06 | The system shall allow patients to change their account password. |
| PAT-07 | The system shall prevent unauthorized users from accessing patient accounts. |

### 1.2 Patient Information Management

| ID | Requirement |
|---|---|
| PAT-08 | The system shall allow patients to provide their full name, age or date of birth, gender, phone number, and address during registration. |
| PAT-09 | The system shall allow patients to update their contact information. |
| PAT-10 | The system shall display the patient's registered information. |
| PAT-11 | The system shall validate required patient information before saving it. |
| PAT-12 | The system shall prevent duplicate patient registration where the same identifying information already exists. |

### 1.3 Appointment Management

| ID | Requirement |
|---|---|
| PAT-13 | The system shall allow patients to view available doctors. |
| PAT-14 | The system shall allow patients to view doctor specialties and relevant information. |
| PAT-15 | The system shall allow patients to view available appointment dates and time slots. |
| PAT-16 | The system shall allow patients to request an appointment with a selected doctor. |
| PAT-17 | The system shall check doctor availability before accepting an appointment request. |
| PAT-18 | The system shall prevent patients from booking an unavailable or already occupied time slot. |
| PAT-19 | The system shall allow patients to view their appointment details. |
| PAT-20 | The system shall allow patients to cancel appointments according to clinic scheduling rules. |
| PAT-21 | The system shall allow patients to request rescheduling of appointments. |
| PAT-22 | The system shall display appointment status, including pending, confirmed, cancelled, and completed. |
| PAT-23 | The system shall allow patients to view their upcoming appointments. |
| PAT-24 | The system shall allow patients to view their previous appointment history. |

### 1.4 Appointment Notifications

| ID | Requirement |
|---|---|
| PAT-25 | The system shall notify patients when an appointment request is submitted. |
| PAT-26 | The system shall notify patients when an appointment is confirmed or rejected. |
| PAT-27 | The system shall notify patients when an appointment is cancelled or rescheduled. |
| PAT-28 | The system shall notify patients about appointment date and time reminders. |
| PAT-29 | The system shall allow patients to view appointment-related notifications. |

### 1.5 Access Control and Privacy

| ID | Requirement |
|---|---|
| PAT-30 | The system shall prevent patients from accessing other patients' private information. |
| PAT-31 | The system shall allow patients to access only their own appointment records. |
| PAT-32 | The system shall restrict patients from accessing doctor, receptionist, administrator, and clinic manager functions. |
| PAT-33 | The system shall protect patient information from unauthorized access. |
