# Smart Clinic Appointment and Patient Scheduling System

## 1. Project Overview
The Smart Clinic Appointment and Patient Scheduling System is a full-scale software solution tailored for healthcare clinics in Ethiopia. It optimizes patient registration, doctor shift management, real-time appointment booking, and medical record keeping while eliminating scheduling conflicts and reducing patient wait times.
